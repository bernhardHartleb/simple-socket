An easy to use modern C++ socket and network library for Linux.

Description

simple-socket is a lightweight C++17 based wrapper around POSIX socket APIs. It keeps the native socket model visible while providing RAII ownership, error handling, poll and convenience functions. The API uses strings for IPv4/6 addresses and keeps pointer handling to a minimum. Blocking socket operations have variants accepting a timeout. Functions for DNS resolution and limited network interface management are included.

Features

  • IPv4 / IPv6 TCP and UDP sockets
  • Unix-domain stream and datagram sockets
  • UDP multicast support (IPv4 only)
  • Timeout support for connect, accept and receive (poll)
  • Peer-disconnect tracking for connected sockets
  • Convenient error handling and stream helpers
  • Hostname and service resolution
  • Network-address and network-interface utilities
  • Optional SocketCAN and SCTP support
  • CMake build, unit tests and example programs

Quick start

Clone the repository and build it using CMake:

$ git clone https://github.com/bernhardHartleb/simple-socket.git
$ cd simple-socket
$ cmake -B build
$ cmake --build build

Documentation

Usage examples are included in the examples directory.

For the complete API and available classes, see the interface documentation.

Usage

To use the library in your own project, it is easiest to add this in your CMakeLists.txt: add_subdirectory(external/simple-socket)

simple-socket uses CMake and includes several unit tests and example programs. There are no external dependencies. The library targets Linux and requires C++17 compiler support; SocketCAN and SCTP support are optional. Source code is released under the MIT License.
