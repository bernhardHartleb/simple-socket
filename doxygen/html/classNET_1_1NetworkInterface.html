std::string NetworkInterface::getBroadcastAddress ( ) const

Return the IPv4 broadcast address of the given network interface.

The IOCTL call SIOCGIFBRDADDR is used on the specified interface. This method only works on AF_INET interfaces. Returns empty string on failure.

Returns
the broadcast address formatted as an ip address
