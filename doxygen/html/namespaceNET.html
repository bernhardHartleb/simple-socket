◆ getNetworkAddresses()

std::vector< NetworkAddressInfo > NET::getNetworkAddresses ( )

Return IPv4/IPv6 address entries for the local network interfaces.

One NetworkAddressInfo is returned per address, so an interface can occur multiple times when it has multiple IPv4/IPv6 addresses. Link-layer entries (AF_PACKET / AF_LINK) are ignored.

Returns
interface address entries returned by getifaddrs()
